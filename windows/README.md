# СВАЛКА для Windows

Нативное приложение для Windows 10 и 11 на C# (.NET 8, WPF). Умеет то же, что Android-версия, и хранит данные в том же формате, поэтому копии подходят в обе стороны.

## Установка и обновления

Скачайте `Svalka-Windows-Setup-<версия>.exe` из [релизов GitHub](https://github.com/cveloy102/reminder/releases). Установщик для Windows x64 работает без прав администратора и кладёт приложение в `%LOCALAPPDATA%\Programs\Svalka`. Ярлык появляется в меню «Пуск». Существующие данные, настройки и аккаунт синхронизации подхватываются и при переходе с переносной версии.

Приложение проверяет стабильные релизы при запуске. В меню **Настройки → Обновления** можно запустить проверку вручную, скачать и установить новую версию. Скачанный файл проверяется по SHA‑256 из GitHub Releases. После обновления нажмите «Открыть СВАЛКУ».

Включённый автозапуск сохраняется при установке и обновлении. СВАЛКА стартует вместе с Windows в трее. При удалении через системный список приложений записи и настройки остаются в `%APPDATA%\Svalka`.

## Возможности

- Четыре списка: дела, покупки, ссылки и мысли, у каждого своя корзина (записи хранятся 30 дней).
- Напоминания с датой и временем, повтор каждый день, неделю или месяц.
- Уведомления Windows с кнопками «Готово», «Через 15 мин», «Через 1 час» и звуком как на телефоне.
- Работа в трее: закрытое окно не мешает напоминаниям; по желанию автозапуск вместе с Windows.
- Закрепление, перестановка перетаскиванием за «⋮», выполненное ниже активного.
- Удаление в корзину с отменой в течение 10 секунд, «Очистить купленное».
- Автокопия в файл на Google Диске (через программу «Google Диск для компьютера»), перенос копии с телефона, сохранение и восстановление из файла.
- Синхронизация с телефоном через свой сервер СВАЛКИ (кнопка синхронизации вверху окна): правки приходят за секунды, токен входа хранится зашифрованным для текущего пользователя Windows. Как поднять сервер — [docs/SELF_HOSTING.md](../docs/SELF_HOSTING.md).
- Светлая, тёмная и системная темы в стиле Терминал, шрифты Inter и JetBrains Mono.

## Управление

| Действие | Как |
| --- | --- |
| Добавить запись | Enter (в «Мыслях» — Ctrl+Enter, Enter переносит строку) |
| Переключить список | Ctrl+1 … Ctrl+4 или вкладки внизу |
| Открыть запись | щелчок по тексту |
| Меню записи | правая кнопка мыши |
| Переставить | перетащить за «⋮» |
| В корзину / восстановить | кнопка ✕ / ↺ при наведении |
| Закрыть окно или выйти из корзины | Esc |

## Где лежат данные

`%APPDATA%\Svalka\data\` — файлы `tasks.json`, `shopping.json`, `links.json`, `thoughts.json` (как на Android).
Настройки — `%APPDATA%\Svalka\settings.json`.

## Сборка

Нужен .NET 8 SDK.

```powershell
cd windows
dotnet test tests\Svalka.Core.Tests
dotnet run --project src\Svalka.Desktop
```

Установщик и переносная сборка, обе со встроенным .NET:

```powershell
./Publish.ps1
```

Готовые EXE лежат в `windows/artifacts/release`. Для следующего выпуска увеличьте `Version` в `Svalka.Desktop.csproj`, пересоберите и опубликуйте установщик как файл стабильного релиза GitHub. Сохраните имя `Svalka-Windows-Setup-<версия>.exe`: по нему Windows-приложение определяет версию установщика.

## Устройство

- `src/Svalka.Core` — модель записей, правила (повторы, корзина, ссылки), хранилище и формат копий. Без привязки к Windows, покрыто тестами.
- `src/Svalka.Desktop` — окно WPF, диалоги, трей, уведомления, автокопия.
- `tests/Svalka.Core.Tests` — тесты логики, в том числе совместимость с копиями Android-версии.
